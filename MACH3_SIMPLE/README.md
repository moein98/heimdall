# MACH3-SIMPLE

A Mach3 parallel-port breakout board: six buffered step/dir axes, six 24 V
sensor inputs, a handwheel switched between jog and THC, and six relays driven
over RS232 by an ATmega328P. It reproduces a board already in service and
matches its connector positions. There is no galvanic isolation.

| Folder | What is in it |
|---|---|
| `fab/` | **What goes to the board house.** `MACH3SIMPLE-gerbers.zip` (2 layers, 1.6 mm FR4, 1 oz, 150.5 x 137.9 mm), BOM, pick-and-place, PDFs |
| `hardware/` | The KiCad 10 project: `MACH3SIMPLE.kicad_pro` |
| `firmware/` | AVR C source; `build/mach3simple.hex` is the built firmware |
| `docs/` | `SPEC.md` - what the board is and why; `COMMISSIONING.md` - bring-up and test, step by step (Persian) |
| `tools/` | The scripts that generate, check and route the design |
| `review/` | ERC/DRC reports, netlist, schematic PDF, board renders |

The schematic and board are generated by scripts, not drawn by hand. To change
the design, edit `tools/build_project.py` or `tools/build_pcb.py` and
regenerate; an edit made in KiCad is lost at the next regeneration.

    python tools/build_project.py                  # schematic
    D:/KiCad/bin/python.exe tools/build_pcb.py --force   # placement (discards routing)
    D:/KiCad/bin/python.exe tools/autoroute.py export    # then Freerouting, then:
    D:/KiCad/bin/python.exe tools/autoroute.py import
    D:/KiCad/bin/python.exe tools/autoroute.py stitch
    KICAD_CLI=D:/KiCad/bin/kicad-cli.exe sh tools/validate.sh
    KICAD_CLI=D:/KiCad/bin/kicad-cli.exe sh tools/fab.sh

Firmware: `sh firmware/build.sh` runs the tests and builds the hex;
`sh firmware/build.sh flash` also sets the fuses and programs the chip through
the ICSP header `J60` with a USBasp. Serial is 9600 8N1. Commands, sent with
Mach3's `SendSerial`: `A`-`F` relay on, `a`-`f` off, `T` handwheel to THC,
`t` handwheel to jog, `?` status.

`mach3 rs232 inputs 6 outputs 6 - pulse 5v - pnp sens.pdf` is the assembly
drawing of the board in service that the layout was copied from.
